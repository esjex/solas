## Now Prototype It: GOV.UK docs for a new audience 

Documentation and content work on an organisation-agnostic fork of the GOV.UK Prototype Kit, covering technical documentation, UX and web copy, and trade show messaging. I rebuilt documentation that had only covered the tool's divergence from its GOV.UK source into a standalone docset that supports users from any organisation, and translated a technical prototyping tool into content that worked for engineering and non-technical audiences alike.

I delivered a Docusaurus-based site from the project's GitHub repo, covering the end-to-end process of users' most common tasks.

## APCOA UK: Internal developer docs from scratch

Engaged as a technical writer and documentation strategist to build internal developer documentation to support the onboarding of new software engineers. This was also a knowledge management role, taking information from across the company and making it discoverable to all engineers.

I delivered an MkDocs-based site on Azure DevOps, covering three major internal systems. Work included restructuring reference documentation for a code generation system and its modifier files, creating onboarding tutorials, standardising C4 architecture diagrams in Mermaid, documenting website architecture, and bringing runbook standards into line across EU and UK deployments. I also built an AI prompt set anchored to [Good Docs Project templates](https://gitlab.com/tgdp/templates), so that the team could sustain documentation quality after the contract ended.

## Skiller Whale: Programmer training courses for engineers

Course research, structure, and writing for a live-coached workshop on pair programming, produced for an e-learning provider specialising in live technical coaching for software engineers.

Working alongside a subject-matter expert who provided the technical depth, I led the research, structure, and writing. I designed the course around information-architecture principles, moving from what pair programming is, through its social and working models, to its application in TDD and the challenges of adopting it. I treated it as a course in communication as much as technique, on the understanding that social cohesion is what actually drives adoption. The result is a 90-minute live-coached workshop, now a standing part of Skiller Whale's catalogue.
