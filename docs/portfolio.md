## APCOA UK

Engaged as a technical writer and documentation strategist to build internal developer documentation from scratch, to support the onboarding of new software engineers.

I delivered an MkDocs-based site on Azure DevOps, covering three major internal systems. Work included restructuring reference documentation for a code generation system and its modifier files, creating onboarding tutorials, standardising C4 architecture diagrams in Mermaid, documenting website architecture, and bringing runbook standards into line across EU and UK deployments. I also built an AI prompt set anchored to [Good Docs Project templates](https://gitlab.com/tgdp/templates), so that the team could sustain documentation quality after the contract ended.
