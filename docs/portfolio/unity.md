# Unity Technologies: Scaling software docs from start-up to enterprise

**Documenting the world's biggest game engine, scaling docs from start-up to enterprise**  
*Senior Technical Writer, Chief Technical Editor*

Over nine years at Unity Technologies I grew from an individual contributor to Chief Technical Editor, and helped scale the documentation team from 4 to 80+ writers. I built the writing guidance and quality standards that still define Unity's documentation today, working across technical documentation, training videos, blog posts, and internal communications. I also mentored junior writers and produced company-wide training materials on technical communication.
