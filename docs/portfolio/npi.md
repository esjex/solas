# Now Prototype It: Converting GOV.UK docs for a new audience

**A standalone docset to take a government tool to the wider market**  
 *Freelance technical content designer · documentation, UX writing, and trade show messaging*

Rebuilt a GOV.UK tool's documentation as a standalone docset any organisation could use, to make the tool ready for user testing and procurement.

[**See live Now Prototype It docs**](https://docs.nowprototype.it/latest/)

### The problem

Now Prototype It is an organisation-agnostic fork of the GOV.UK Prototype Kit. Its initial documentation mainly covered where the tool diverged from its GOV.UK source, which left information gaps for users coming from outside the government ecosystem. The tool needed documentation to support demos, user testing, and procurement processes. The client also required broader technical communications support, including UX writing and trade show messaging.

### The goal

A minimum-viable standalone docset that could support users from any organisation, not just those already fluent in GOV.UK tools.

### Approach

* **Audited the existing documentation** to map what was covered, what was assumed, and where the GOV.UK-specific docs left non-government users stuck.  
* **Used the product as a new user would**, working through it hands-on and noting exactly where I got stuck, to turn my own friction points into the docset's priorities.  
* **Defined and documented the common tasks** a user would actually perform, building the minimum coverage needed for the whole process to make sense end-to-end, including how the different components and products relate to one another.  
* **Chose tooling that fit.** I selected Docusaurus, a static site generator aligned to the client's existing tools and workflow, so documentation lives alongside their code and integrates with how they already work, rather than becoming a separate system to maintain.  
* **Supported marketing content**, writing trade show messaging and representing the client at UK GovCamp 2026.

### Outcome

NPI now has a minimum-viable docset that documents the whole prototyping process and describes how its components and products fit together; standalone enough to support users from any organisation, and to underpin user testing and procurement processes. The product and its messaging also drew strong, enthusiastic interest at UK GovCamp 2026.
